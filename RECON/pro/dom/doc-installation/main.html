Install with the CLI

Recommended: the shadcn CLI adds files and dependencies for you.

Before you start

  • Node.js 18 or newer
  • A React project with shadcn/ui initialized : run npx shadcn@latest init if you haven't
  • A components.json file in your project root (created by shadcn init)
1

Add your license key

Create or update .env.local in your project root: the same folder as package.json.

REACTBITS_LICENSE_KEY=your-license-key-here
2

Register the registries

Add the registries section to your components.json, merging with any existing content.

{
  "registries": {
    "@reactbits-starter": {
      "url": "https://pro.reactbits.dev/api/r/starter/{name}.json",
      "headers": {
        "Authorization": "******"
      }
    },
    "@reactbits-pro": {
      "url": "https://pro.reactbits.dev/api/r/pro/{name}.json",
      "headers": {
        "Authorization": "******"
      }
    }
  }
}

@reactbits-starter serves components and the setup skill (Starter+). @reactbits-pro serves blocks, Application UI and the Agent Kit (Pro & Ultimate).

3

300 blocks of product chrome: app shells, data tables, dashboards, settings and AI surfaces. Same registry, same naming rule. Add -sorbet for the Sorbet style, as in ai-chat-1-sorbet.

Pro & Ultimate

Where the setup skill teaches your agent how to install, the Agent Kit tells it what to build: 8 design skills for the look, 8 page prompts for the vertical, and 3 recipes that name the exact blocks in order. Hand over a skill and a prompt together and you get a full page.

npx shadcn@latest add @reactbits-pro/prompt-saas
