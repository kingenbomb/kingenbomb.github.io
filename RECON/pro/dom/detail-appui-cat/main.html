Our depot capacity model is off by roughly 8% on Tuesdays. Where should I look first?

Tuesday is the only day the model reads the carrier feed before the overnight reconciliation finishes, so a slice of Monday's late arrivals is counted twice. Start with the ingest window in loaders/carrier_feed.py, then compare the reconciled totals for the last four Tuesdays against the raw feed.

Makes sense. Draft the fix and list what it changes.

The patch moves the ingest cutoff to 04:00 so it always lands after reconciliation, drops the duplicate rows that the old window let through, and adds a regression test that replays four weeks of Tuesday feeds. Nothing outside the loader changes, and last week's totals fall back in line to within 0.3%.

Does the test catch the reverse case, where reconciliation finishes late?

It does. The fixture parametrises the reconciliation finish time, so a run that lands at 05:10 fails on row counts instead of passing quietly. I also kept the old window behind a flag for one release, which lets you diff both outputs on staging before the cutover.

Q3 retention review

Summarize why net revenue retention dropped in Q3.

Net revenue retention fell to 104% from 111% the prior quarter. The decline is concentrated in the mid-market segment, where two large accounts downgraded after a reorganization. Expansion held up in enterprise, but new upsells slowed after the pricing change.

What would recover it fastest?

The quickest lever is re-engaging the two downgraded mid-market accounts, which together account for four of the seven points lost. A targeted win-back offer before renewal would address most of the gap, and reversing the upsell slowdown means revisiting the new tiers.

Which segment held up best?

Enterprise held up best: expansion there was roughly flat, so almost all of the drag is coming from mid-market rather than a broad-based decline. Gross retention in enterprise actually improved slightly, which is why the net number didn't fall further.

pricing-table.tsx
type Plan = {
  name: string
  price: string
  period: string
  cta: string
}

export function PricingTable({
  plans,
}: {
  plans: Plan[]
}) {
  return (
    <div className="grid gap-4">
      {plans.map((plan) => (
        <article key={plan.name}>
          <h3>{plan.name}</h3>
          <p>{plan.price}</p>
          <span>{plan.period}</span>
          <button>{plan.cta}</button>
        </article>
      ))}
    </div>
  )
}
