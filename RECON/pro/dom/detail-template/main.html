About this template

A website for an AI agent platform, with a pixel landscape, cobalt accents, and interactive product storytelling. Agentframe pairs a detailed landing page with dedicated pricing, editorial, and About pages. Task runs, workspace controls, and SDK examples are working frontend demonstrations, ready to adapt to your own product.

Special Features

  • Animated pixel landscape with water ripples and pointer interaction
  • Custom task selector with three local run-and-replay scenarios
  • TypeScript and Python SDK examples with tabs and clipboard feedback
  • Interactive context, permissions, approval, and workspace previews
  • Animated three-stage agent run diagram with keyboard-operated tabs
  • Pricing page with monthly/yearly billing and a competitor comparison
  • Field notes index and three complete article pages
  • Responsive layouts, light/dark themes, and persistent motion controls
  • Keyboard navigation, modal focus handling, and reduced-motion support
  • Original branding, metadata, structured data, icons, and sitemap
