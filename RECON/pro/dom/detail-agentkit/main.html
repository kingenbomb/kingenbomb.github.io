The Apple look is not "clean and minimal". It is a set of hard rules that most agents break instantly: exactly one idea per full-viewport section, a type scale that jumps 3–4 steps between headline and body with no timid mid-sizes, an 8-point spacing grid where vertical rhythm is measured in hundreds of pixels, and a colour palette of two neutrals plus the product's own colours.

This skill encodes the composition, type, spacing, motion, and most importantly, the 38 anti-patterns that make an "Apple-inspired" page read as a cheap imitation: gradient headline text, glassmorphism everywhere, three-up feature card grids, emoji icons, rounded-full pill badges above every heading, and section padding that never exceeds `py-24`.
